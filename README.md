# Personal Portfolio – HTML & CSS

## Overview

This is my **personal portfolio website**, built to showcase my front-end skills, projects, and design sense.  
It represents my first complete portfolio created using core web technologies.

## Features

- Clean and simple UI
- Responsive design (mobile, tablet, desktop)
- About Me section
- Projects showcase with links
- Contact section with social links
- Smooth navigation between sections

## Technologies Used

- HTML5
- CSS3
- Responsive Design (Flexbox / Media Queries)
